Open questions to resolve

  • Account resolution No PS API to create accounts. Must use existing. Pre-configured default per UC instance, or admin-selectable mapping?
  • Portfolio strategy Create new portfolio per project (noisy), map to single default (simple), or admin-configured mapping? If new — naming convention?
  • CompanyId mapping Is there a 1:1 between UC orgs and PS companies? If not, needs admin configuration or a conditional dropdown on the form.
  • WorkflowState default What initial state for new PS projects? "Active"? "Planning"? Are PS workflow states standardized or fully custom per account?
  • Sequence field PS requires Sequence (appears to be a project numbering scheme with optional prefix/suffix). Auto-generate counter within portfolio? Derive from UC project number?
  • Additional field mappings Beyond Name, should Address/City/State/Zip carry over? Should "Link to Trimble Connect project" auto-toggle on PS side? What about Prefix, Suffix, Number?
  • Error handling & rollback If PS creation fails after UC save succeeds — retry? Surface error and let user retry manually? Rollback UC save? Queue for async retry?
